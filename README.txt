ОТКРЫТКА ДЛЯ ЖАНЫМ — инструкция

1. Откройте index.html в браузере, чтобы посмотреть сайт.
2. Перед публикацией отредактируйте index.html:
   - даты и тексты в блоке «Наша история» (все основные даты уже внесены);
   - письмо — внутри section id="letter";
   - подпись и год внизу страницы.
3. Фотографии:
   - кнопки выбора фото позволяют предварительно посмотреть изображения в текущем браузере;
   - чтобы фотографии были видны всем по ссылке, положите файлы в папку сайта и добавьте в HTML теги <img src="photos/photo1.jpg"> (либо замените плейсхолдеры изображениями).
4. Музыка «Сон» — Эндшпиль, HLOY, Mav-d:
   - положите свой легально полученный аудиофайл этой песни в ту же папку, где находится index.html;
   - назовите файл строго son.mp3;
   - после этого кнопка «Включить „Сон“» будет запускать и останавливать трек. Сам аудиофайл в архив не включён.
5. Бесплатная публикация:
   - создайте репозиторий на GitHub, загрузите index.html;
   - Settings → Pages → Deploy from a branch → main → /(root) → Save;
   - дождитесь появления адреса сайта.
6. Папка подходит для размещения на GitHub Pages, Netlify или другом статическом хостинге.

Даты в истории: начало отношений — 6 января 2026; предложение — 17 мая 2026; никах — 19 сентября 2026; свадьба — 17 октября 2026. Локально выбранные фото не встраиваются в сайт автоматически.

Открой папку photos и прочитай файл ПОЛОЖИ_СЮДА_5_ФОТО.txt. Добавь туда пять изображений с указанными именами. Не переименовывай саму папку photos. При публикации загружай index.html и папку photos вместе.
